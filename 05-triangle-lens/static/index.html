How it works

1. Rules first. Keyword and regex rules (editable in Settings) always flag the obvious checks, for example a meta-analysis always needs PRISMA.

2. Llama adds judgement. The local model reads the title, abstract and tags, then returns the category, study type, specialty, extra checks, points to double-check and a confidence score. It can add checks but never remove a rule-triggered one.

3. You decide. Override the specialty, tick checks off as you complete them, assign to a person, add notes, and export everything to CSV.

Tip: add abstracts. With titles alone the model is told to lower its confidence.
